# مصروفاتي برو (Expense Tracker Pro PWA)

تطبيق ويب تقدمي (PWA) متطور ومخصص لتتبع وإدارة المصروفات اليومية والعهد النقدية بدقة عالية، مع دعم كامل للأوامر الصوتية والعمل بدون إنترنت.

## 🚀 المميزات الرئيسية
* **أوامر صوتية ذكية:** تسجيل المصروفات بالصوت باللغة العربية مع استخراج المبالغ والتصنيفات تلقائياً.
* **إدارة العهدة والذمم:** فصل دقيق بين العهدة النقدية (كاش)، المشتريات بالبطاقة، والمبالغ المدفوعة من الحساب الشخصي.
* **الوضع الليلي (Dark Mode):** تصميم مريح للعين يدعم التبديل السلس بين الوضع الفاتح والداكن.
* **التقارير والتصدير:** إمكانية تصدير البيانات بصيغة CSV، حفظ نسخة احتياطية (JSON)، أو طباعة تقارير PDF مفصلة.
* **العمل بدون إنترنت (PWA):** يعمل التطبيق محلياً بالكامل بفضل تقنية Service Worker مع إمكانية تثبيته مباشرة على الشاشة الرئيسية للهاتف.

## 📁 هيكل المشروع
* `index.html`: واجهة التطبيق والمنطق البرمجي الأساسي.
* `manifest.webmanifest`: إعدادات وتكوين تطبيق الـ PWA.
* `sw.js`: ملف Service Worker للتخزين المؤقت والتشغيل أوفلاين.
* `404.html`: صفحة خطأ مخصصة.
* `icons/`: أيقونات التطبيق بأحجام مختلفة.

## ⚙️ التشغيل والاستخدام
فقط افتح ملف `index.html` في أي متصفح حديث، أو قم بتثبيت التطبيق على هاتفك من خيارات المتصفح للاستفادة من كامل الميزات!
